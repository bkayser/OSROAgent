# For Assignors

This page is for assignors and administrators who use the Oregon Soccer Referee Concierge.

## Using the Concierge

* The chatbot can answer referee and league questions using ingested documentation from RefTown, OYSA, NWSC, and OSRO.
* Referees can look up their USSF license status directly from the chat or via **Look up License Info** in the menu.

## Feedback and Corrections

If information for your league or organization is missing or incorrect, please submit feedback using the link at the bottom of the page. We use feedback to improve the knowledge base and add new sources.

## Beta

We are currently in Beta and welcome stress-testing with league-specific queries.
