# About Oregon Soccer Referee Concierge

This application is a specialized AI chatbot for Oregon soccer referees. It uses a custom knowledge base grounded in regional data to answer questions about IFAB and league rules, referee procedures, getting assignments, and using Reftown.


## How It Works

* **Knowledge base:** We ingest documentation from RefTown, OYSA, NWSC, and the Oregon Soccer Referee Organization.
* **License lookup:** The bot can query public USSF data to show your license status and expiration dates.
